# Rotary Club of Rumuomasi

A Next.js website for the Rotary Club of Rumuomasi, designed around service, community impact, and Rotary values. The site includes a branded landing page, project and news sections, membership and donation flows, and a floating scroll-to-top action.

## Features

- Rotary-inspired landing page and branding
- Project showcase with detail pages
- News archive and story pages
- Membership application form
- Donation form
- Scroll-to-top floating action button
- Responsive UI built with Next.js and Tailwind CSS

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the app locally:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Production Build

```bash
npm run build
```
